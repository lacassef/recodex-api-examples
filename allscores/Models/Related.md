# Related

A **Related** entity is a competition, competitor, or athlete linked to the ones you asked for.

**Where you'll see it:** the related-entities route.

**Related models:** [Competition](Competition.md), [Competitor](Competitor.md), [Athlete](Athlete.md).

## Properties

- **id** (`number`):
    - Id of the linked entity. Send it with the parameter name the next operation lists.

- **name** (`string`):
    - Display name.

- **nameForURL** (`string`):
    - Name used in a path.
