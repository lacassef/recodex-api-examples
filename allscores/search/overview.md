# Search

GET `/api/allscores/search`

- `query` — the text
- `filter` — `all` returns every result type
- `sport`

The body returns competitions, competitors, and athletes, plus the sports and countries needed to label them. Read `id` from the list you open next. Which parameter name that id uses is in [Parameters](../guides/request-essentials.md). A filled call is in [Examples](../guides/examples.md).
